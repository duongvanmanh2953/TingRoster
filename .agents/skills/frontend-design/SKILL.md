# Frontend Design Skill

## Core Principles
1. **Purposeful Aesthetics**: Clean, modern, high-contrast, uncluttered SaaS aesthetic. Avoid gratuitous gradients or distracting animations.
2. **Design Tokens & System**: Standardize colors, typography, borders, and shadows using Tailwind tokens and CSS variables.
3. **Mobile-First Responsiveness**: Every view must adapt gracefully from small mobile screens (375px+) to large desktop displays (1440px+).
4. **Touch & Ergonomics**: Buttons, tabs, and interactive targets must be at least 44x44px on mobile devices.
5. **State Feedback**: Provide immediate visual feedback for loading, disabled, hover, active, empty, and error states.
6. **Accessibility (a11y)**:
   - Proper WCAG AA color contrast.
   - Semantic HTML (header, main, nav, section, article).
   - ARIA labels on icon-only buttons.
   - Focus rings visible on keyboard navigation.
7. **Consistent Vietnamese Localization**:
   - Natural, professional Vietnamese terminology.
   - Consistent financial and status labels (e.g. "Chưa đóng", "Đóng thiếu", "Đã đóng", "Giao dịch chưa khớp").
